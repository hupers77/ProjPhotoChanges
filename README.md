# 포토웍스 웹 (photoWORKS 웹 버전)

사진 여러 장을 한 번에 크기 조정해 개별 파일로 저장하는 브라우저 앱입니다.
사진은 서버로 올라가지 않고 브라우저 안에서만 처리됩니다. 빌드 과정 없이 정적 파일만으로 동작합니다.

## 실행 방법 (맥)

처음 한 번 저장소를 받습니다.

```
cd ~
git clone https://github.com/hupers77/ProjPhotoChanges.git projphotochanges
cd projphotochanges
```

이후에는 이 폴더에서 아래를 실행하고 Chrome으로 http://localhost:8000 을 여세요.
최신 코드는 `git pull`로 받습니다.

```
python3 -m http.server 8000
```

ES 모듈을 쓰기 때문에 `index.html`을 더블클릭(file://)하면 열리지 않습니다.
GitHub Pages 같은 정적 호스팅에 그대로 올려도 됩니다.

## 지금 되는 것 (1단계)

- 사진·폴더 끌어다 놓기, 사진 선택, 폴더 선택 (하위 폴더 포함)
- 크기 조정: 긴 변, 짧은 변, 가로, 세로, 가로×세로 상자 안에 맞추기, 비율(%), 원본 유지 / 확대 방지
- 저장 형식: 원본과 같게, JPEG, PNG, WebP, 화질(50~100)
- 파일 이름 규칙: `{원본}` `{순번}` `{순번3}` `{순번4}` `{날짜}` `{시간}`
- 저장: Chrome·Edge는 고른 폴더에 개별 파일로 바로 저장(같은 이름은 덮어쓰지 않고 ` (1)` 붙임),
  Safari·Firefox는 한 장씩 개별 다운로드
- 사진 방향(EXIF Orientation)은 자동으로 바로 세워서 저장
- 설정은 이 브라우저에 기억됨

## 구조

| 파일 | 역할 |
|---|---|
| `js/settings.js` | 모든 설정을 담는 객체, 기본값, 저장/불러오기 (3단계 프리셋이 이 객체를 통째로 저장) |
| `js/resize.js` | 목표 크기 계산, 단계적 축소로 고화질 리사이즈 |
| `js/pipeline.js` | 사진 1장 처리: 디코드 → 리사이즈 → 오버레이 → 인코딩. `registerOverlay()`로 2단계 서명·EXIF가 끼어듦 |
| `js/filename.js` | 파일 이름 규칙 |
| `js/exporter.js` | 폴더 저장 / 개별 다운로드 |
| `js/main.js` | 화면 연결 |

## 알려진 한계 (다음 단계에서 다룸)

- 저장된 파일에는 원본 EXIF가 남지 않음 (캔버스 인코딩 특성). 2단계에서 EXIF 읽기와 함께 보존 여부를 정함
- `{날짜}`는 지금은 파일 수정 날짜. 2단계에서 촬영일시로 바꿀 수 있음
- HEIC는 Safari에서만 열림 (Chrome은 브라우저가 HEIC를 지원하지 않음)
